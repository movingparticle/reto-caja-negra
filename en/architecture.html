FRONTIER Bogotá 2026 · Challenge 2 · 12:00 milestone.
A service has been running in production for 10 years and nobody knows how it works. We'll discover its behavior by observing it and build a replica that responds exactly the same — errors included — without ever calling it at runtime.

01 // what

Replace a system with no code and no documentation with a deterministic, byte-for-byte replica, against cases we don't know.

02 // how

Hypothesis-driven probing to infer the real rule, and a native in-memory HTTP server that emulates commands, states and errors.

03 // proof

Differential comparison oracle vs. replica, an adversarial battery, and exact parity of status and body.

Worker

Production entrypoint: CORS, routing, timing-safe auth and an 8 KiB body limit (E101). Unknown routes → 404 E404.

Durable Object

Single instance global-caja-negra: guarantees one state across requests, isolated by POST /__reset.

Engine + checksum

Deterministic state machine. Control with ISO 7064 Mod 97-10; error precedence and ANULA reversal.

Runtime of one test

POST /__reset → state 0 → POST /msg (1 to 12 requests) → validation → transition → exact body. More than 5 s is a failure.

Deployment

Worker + Durable Object on Cloudflare's edge. A single logical state; verified live (20/20 examples).
