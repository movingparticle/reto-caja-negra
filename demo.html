¿Qué es esto? Un probador manual de un solo mensaje contra el worker real (no forma parte de la batería de 95 casos):
1) Escribe un mensaje del protocolo CMD;arg;… (ej. ALTA;Carlos).
2) Pulsa $ calc_iso97 → le calcula y agrega el dígito de control ISO 7064 (queda tipo ALTA;Carlos;42). Si no lo pulsas, ENVIAR lo agrega solo (con la casilla de abajo activada).
3) Pulsa > ENVIAR → lo manda de verdad (POST /msg) y abajo verás la respuesta cruda: código HTTP + JSON del worker.
Comandos que puedes escribir (escribe solo el comando; el control lo agrega el botón):
PING → prueba de vida (responde pong)
ALTA;Nombre → crea cuenta (devuelve AC-0001, AC-0002…)
CONSULTA;AC-0001 → muestra el saldo de una cuenta
DEPOSITO;AC-0001;50000 → abona un monto
TRANSFER;AC-0001;AC-0002;1000 → mueve saldo (máx 50000)
ANULA;OP-0001 → revierte una operación
HALT;1 → detiene el servicio (503; se recupera con POST /__reset)
